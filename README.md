# Hoops GM

An original basketball team-management (GM) sim that runs in the browser. Fictional league, generated players. Not affiliated with or based on any licensed league or game.

```bash
npm install
npm run dev        # then open /design for the design system
npm run build
npm run contrast   # WCAG check on replica/design/tokens.json
```

Planning docs live in `replica/`: recon, architecture, schema, and the design system.
